# 里程碑 M1：可用的 2D PV 编辑器核心

记录时间：2026-11-07
仓库：PVForge（GitHub 仓库根目录）
用途：压缩上下文后快速恢复项目状态。

## 一句话状态

用 Mine-imator 式工作流（对象树 + 时间轴 + 关键帧 + 相机式后处理）做 2D 音乐 PV 的编辑器核心已经可用：建项目、放图片/视频/文字/矢量、打关键帧、播放、撤销、保存/加载、素材打包。

**尚不能导出视频**，这是出片闭环的最后缺口。

## 里程碑 M2：音频与波形（进行中）

记录时间：2026-11-07

目标：让音乐 PV 能对着 BGM 波形卡点，再逐步接入播放和导出。

### 依赖策略

- 解码、重采样、格式探测全部走 **FFmpeg**（系统包），不自己写 FLAC/MP3/AAC 解码
- 播放走 **Qt 6 Multimedia `QAudioSink`**（系统 Qt 包）
- FLAC/OGG/Opus 等由 FFmpeg 内置解码器处理；需要 libflac 时用发行版包，不内嵌第三方源码
- 这样音频格式支持跟着系统 FFmpeg 走，减少自维护解码器的消耗

### 已定设计

- 音频是时间轴对象（`EntityType::Audio`），不是单独固定音轨
- 字段：`startFrame`、`trimStart`、`trimEnd`、`volume`、`fadeIn`、`fadeOut`、`duration`
- 波形数据：48kHz 立体声 int16 PCM 用于播放；1ms 峰值包络用于波形绘制
- 波形峰值按像素聚合，不在 `paintEvent` 扫原始 PCM
- 音频对象显示在时间轴行里；后续加高/独立大波形条供字幕对齐
- 播放以音频为主时钟；没有音频时退回 `QElapsedTimer`
- 音频属性先静态，音量关键帧后续复用现有 Track

### 分步

1. FFmpeg 音频解码 + 1ms 峰值 + 波形缩略图
2. 音频实体、工作台导入、素材库、时间轴波形行
3. Qt Multimedia 播放、混音、播放头同步
4. 裁剪/移动/音量属性与撤销
5. 导出时复用同一混音器

当前完成：1–3 的首版；时间轴音频行高 56px，裁剪/音量/开始帧属性可用但未接撤销；独立大波形条和音量关键帧后续补。

## 已实现

### 工程

- 欢迎页：最近项目、新建项目、打开项目
- 新建项目对话框：名称/位置/分辨率/帧率/作者/描述
- `.pvproj` JSON 工程格式，相对路径，关闭未保存提示
- 标题栏显示 `[未保存]` / `[已保存]`
- 时间轴长度动态：取最长素材与最后关键帧，空工程为 0，播放头可无限前进

### 实体

- 图片、视频（首帧）、文字、矢量、摄像机
- 文字：内容/字体/字号/颜色/对齐
- 矢量 9 种形状：矩形、圆角矩形、椭圆、直线、三角形、心形、星形、多边形、箭头
  - 参数：宽高、圆角、边数、内径比、填充、描边
- 每实体：位置、旋转、缩放、透明度、隐藏、锁定
- 摄像机：时间轴对象，活动摄像机、取景比例 5%–100%、旋转、关键帧；位置限制在画布内，旋转允许越界
- 自定义轴心（`rotPointX/Y`）：位置锚定轴心，改轴心自动补偿位置，旋转围绕轴心
- 锁定在数据层强制：值、关键帧不可改

### 动画与时间轴

- 逐属性关键帧轨道，支持线性、瞬间、30 种缓入/缓出/缓入缓出预设和自定义三次贝塞尔
- 右键关键帧或属性面板「关键帧」的「缓动：…」按钮打开视觉曲线模板网格；曲线属于到达的关键帧（进入段）
- 缓动由目标关键帧控制：设置 1s 的曲线影响 0s → 1s；第一帧没有进入段
- `Track::evaluate` 按缓动曲线插值
- 自动关键帧（默认开）
- 时间轴：固定缩放 + 横向滚动 + 自动跟随播放头
- `Ctrl+滚轮` 缩放（0.25–32 px/帧）
- 刻度行自适应：秒模式每秒按项目帧率均分为整数格（24 fps → 24/12/8/6/4… 格），帧模式按 1/5/10/20/50 帧分档并标帧号
- 刻度行可切换显示秒数或帧号（时间轴左上角「秒 / 帧」按钮或视图菜单，设置持久化）：帧模式只有帧号，秒模式只有秒
- 状态栏跟随当前单位：帧模式显示帧号，秒模式显示秒数，不再混排
- 点刻度行后 `←` / `→` 单帧步进；按住约 0.4 秒后开始按工程帧率连续播放 / 倒退，轻按只走一帧
- 刻度行拖播放头；轨道空白点击跳转；点关键帧选中不跳转
- 框选关键帧（行 × 帧范围），高亮选中
- 关键帧可以 `Delete` 删除，撤销恢复
- 时间轴左侧搜索框过滤对象
- 行内按钮（悬停）：隐藏、锁定、全选关键帧
- 双击对象名重命名

### 视口交互

- 选中框 + 四角缩放手柄
- Gizmo：X 右 / Y 上直角轴 + 旋转圆环
- 拖轴单轴移动，拖环旋转，拖本体自由移动
- 自定义轴心时：拖轴/白点移动轴心，关闭编辑后拖轴移动实体
- PPT 式角缩放：对角固定，位置补偿
- `Ctrl` 等比缩放；拖过中心镜像
- 吸附：画布中心线/边缘/四角、其他正交实体的边缘与四角
- 旋转吸附：默认 0°/90°，可开 180°/270°，容差 3°
- 拖动主轴约束（4:1）与青色对齐参考线
- 所有吸附可被 `Ctrl` 临时关闭

### 摄像机与监视器

- 工作台「摄像机」类型，只填名称；创建即选中并设为活动摄像机；没有摄像机时监视器显示工作摄像机
- 视口只显示活动摄像机取景框；框外 55% 深灰半透明压暗，框内点击穿透给实体；视图菜单可隐藏取景框
- 拖动边框/标题条移动，四角中心固定缩放，顶边旋转手柄；移动吸附沿用画布/实体，旋转沿用角度吸附
- 活动摄像机 ID 和监视器视图存进工程；监视器位置/大小/画质/独立窗几何存全局设置
- 监视器下拉：工作摄像机 / 场景摄像机 / 整画布；无辅助线、无选中框，等比黑边
- 监视器标题栏显示帧率：静止时项目帧率，播放时每秒统计实际刷新率；低于项目帧率时变红
- 草稿默认按监视器分辨率并使用缩略图；高质量按项目分辨率并使用原图；播放强制草稿，暂停恢复
- 画布内显示项目背景，画布外纯黑；工作摄像机显示主视口原始内容（包括画布外）
- OBS 式独立窗口：按钮或拖出主窗口；关闭独立窗口停靠回右下角；默认不置顶，可切换「置顶」
- 共享 `SceneRenderer` / `CameraRenderer`，主视口、监视器、未来 MP4 导出共用

### 音频与波形

- 音频是时间轴对象：开始帧、裁剪开始/结尾、音量、淡入淡出；开始帧/裁剪字段右侧「取」按钮直接取播放头位置
- FFmpeg 系统包解码（含 FLAC/OGG/Opus 等），统一为 48kHz 立体声 int16
- 1ms 峰值包络；时间轴音频行按波形峰值绘制，音频行高 56px
- 工作台「媒体」和素材库支持导入音频；波形缩略图进素材库
- Qt Multimedia `QAudioSink` 播放；多音频混音、裁剪、音量、淡入淡出
- 有音频时以音频播放位置驱动动画播放头
- 拖动播放头/逐帧时播放 150ms 短片段（音频擦洗），视图菜单可关闭；默认开启
- PCM/波形是运行时缓存，工程只存哈希路径和参数

### 素材
- 工作台：媒体（图片/视频自动识别）、文字、矢量图标网格、内嵌素材库
- 素材库：`+` 多文件导入、搜索、预览、创建实体、删除（可选同时删实例）
- 异步导入：哈希/复制/解码在工作线程，状态栏进度条
- 内容寻址存储：`assets/<sha256>.<ext>`，天然去重，显示名保留
- 「全部打包到项目」开关（默认关），工程内素材存相对路径
- 视频时长参与时间轴长度

### 撤销 / 重做

- 覆盖：属性修改、实体创建/删除、隐藏锁定、重命名、关键帧删除、移动、缩放、轴心、摄像机移动/缩放/旋转
- 连续拖动合并为一条：移动、缩放、轴心、单轴、旋转、摄像机
- `Ctrl+Z` / `Ctrl+Shift+Z`

### 界面

- 右侧页签：项目属性（项目设置/环境设置/素材库）、实体属性页签（按需出现）
- 面板内容可折叠、可滚动
- 时间轴和视口配色跟随系统主题，图标优先用桌面图标主题；缓动缩略图和贝塞尔图表用 QPalette 自绘，暗色已验证
- 设置页：qBittorrent 式左侧分类 + 右侧内容页（常规、编辑器、新项目、时间轴、素材、解码、关于）；关于页显示系统/CPU/内存/显卡/显示器/Qt/FFmpeg 与当前解码路径，可一键复制；帮助菜单的「关于 PVForge」也打开该页
- 语言文件 `assets/lang/zh_CN.json` / `en_US.json`（核心界面）

## 架构

```
src/
├─ core/     Project/Entity/Track/Keyframe、History+Commands、Settings、Lang、VectorShape、Camera、Easing
├─ anim/     （预留）
├─ render/   SceneRenderer（共享实体绘制）、CameraRenderer（场景/工作摄像机取景）
├─ media/    VideoDecoder（FFmpeg 首帧）、AudioDecoder/AudioClip（音频解码与波形）、MediaImporter、DecoderInfo
├─ audio/    AudioEngine（离线混音 + QAudioSink 播放）
├─ export/   （预留）
├─ ui/       Viewport、TimelinePanel、PropertiesPanel、AssetLibraryPanel、
│            ProjectPropertiesPanel、EnvironmentPanel、WorkbenchPanel、
│            CameraMonitor、EasingPicker、BezierEditorDialog、CollapsibleSection
└─ app/      MainWindow、WelcomeWindow、NewProjectDialog、SettingsDialog、SystemInfo、AppIcon
```

关键设计：

- **位置 = 轴心**：变换 `T(pos) · R · T(-pivot) · S`，改轴心补偿位置，视觉不动
- **摄像机 = 画布内的旋转取景框**：位置/缩放/旋转复用实体轨道；未旋转框限制在画布内，旋转可越界，画布外纯黑
- **共享渲染器**：主视口、监视器、未来导出都走 `SceneRenderer`；辅助线和压暗只留在主视口
- **内容寻址素材**：哈希文件名 + 原始显示名
- **命令历史**：复合命令 + 合并，一次拖动一条撤销
- **缓动归属目标关键帧**：设置到达 1s 的曲线，就改 0s → 1s 这一段；和 Mine-imator 的“出发段”模型相反，目的是符合“到这个姿势”的直觉
- **异步导入**：重活在工作线程，主线程入库
- **解码策略**：当前视频首帧和音频全部走 FFmpeg 软件解码；启动时禁用 Qt Multimedia 硬件视频后端，避免 VDPAU/VAAPI 探测；视频播放接入后再做真正的硬件解码设置
- **音频主时钟**：有音频时播放头跟随 `QAudioSink` 实际播放位置；无音频才用计时器
- **求值/渲染未分离**：渲染器仍逐帧读 Project；导出前需要抽出 FrameSnapshot（见下一步）

## 已知限制

- 没有视频导出（MP4）
- 视频只显示首帧，无逐帧播放
- 无频谱可视化对象（音频轨波形已支持）
- 音频属性修改暂未接入撤销栈
- 音频擦洗是短片段预览，不是变速连续擦洗
- 音频波形目前只有 1ms 峰值、没有独立的整轨大波形页
- 音频工程加载时同步解码；长音频可能卡一下
- 关键帧缓动目前是单段模板/贝塞尔，没有整轨曲线图
- 关键帧不能拖动改时间、复制、粘贴
- 旋转实体的角缩放仍围绕中心
- 实体单选（框选只作用于关键帧）
- 英文翻译只覆盖核心界面
- 摄像机不支持自定义输出分辨率/宽高比（竖屏裁切）；监视器没有无边框全屏投影
- 3D 世界/Minecraft 资产完全移除（有意）

## 下一步：关键帧曲线与编辑

缓动基础已经实现（预设 + 自定义贝塞尔），下一步按优先级：

1. **整轨曲线编辑器**
   - 下方可切换「图表编辑器」页，显示当前属性曲线
   - 直接在图表上拖贝塞尔控制点和关键帧
   - 时间轴关键帧右键仍保留快速切换预设
2. **关键帧编辑**
   - 拖动关键帧改时间（吸附帧）
   - 复制/粘贴/剪切、框选移动
   - 多选关键帧共享缓动编辑
3. **关键帧函数（更远）**
   - 类似表达式：位置/旋转可绑定到时间、音频振幅、另一实体属性
   - 需要先抽出求值器（Project → FrameSnapshot），避免 UI 与渲染直接耦合
4. **导出 MP4**
   - 逐帧渲染到 FBO/QImage → FFmpeg 编码 → 音频混流
   - 复用同一求值路径，保证所见即所得

## 运行

```bash
cd PVForge
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/pvforge
```

依赖：Qt 6（Widgets/Concurrent/Multimedia）、FFmpeg（含 libswresample）、Clang 21、CMake 4。
