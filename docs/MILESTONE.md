记录时间：2026-11-07
仓库：PVForge（GitHub 仓库根目录）
用途：压缩上下文后快速恢复项目状态。

## 一句话状态

用 Mine-imator 式工作流（对象树 + 时间轴 + 关键帧 + 相机式后处理）做 2D 音乐 PV 的编辑器核心已经可用：建项目、放图片/视频/文字/矢量、打关键帧、播放、撤销、保存/加载、素材打包、MP4 导出。

## 里程碑 M2：音频与波形（已完成）

记录时间：2026-11-07

目标：让音乐 PV 能对着 BGM 波形卡点，再逐步接入播放和导出。

### 依赖策略

- 解码、重采样、格式探测全部走 **FFmpeg**（系统包），不自己写 FLAC/MP3/AAC 解码
- 播放走 **Qt 6 Multimedia `QAudioSink`**（系统 Qt 包）
- FLAC/OGG/Opus 等由 FFmpeg 内置解码器处理；需要 libflac 时用发行版包，不内嵌第三方源码
- 这样音频格式支持跟着系统 FFmpeg 走，减少自维护解码器的消耗

### 已定设计

- 音频是时间轴对象（`EntityType::Audio`），不是单独固定音轨
- 字段：`startFrame`、`trimStart`、`trimEnd`、`volume`、`fadeIn`、`fadeOut`、`duration`
- 波形数据：48kHz 立体声 int16 PCM 用于播放；1ms 峰值包络用于波形绘制
- 波形峰值按像素聚合，不在 `paintEvent` 扫原始 PCM
- 音频对象显示在时间轴行里；后续加高/独立大波形条供字幕对齐
- 播放以音频为主时钟；没有音频时退回 `QElapsedTimer`
- 音频属性先静态，音量关键帧后续复用现有 Track

### 分步

1. FFmpeg 音频解码 + 1ms 峰值 + 波形缩略图
2. 音频实体、工作台导入、素材库、时间轴波形行
3. Qt Multimedia 播放、混音、播放头同步
4. 裁剪/移动/音量属性与撤销
5. 导出时复用同一混音器

当前完成：全部完成；时间轴音频行高 56px，可在时间轴直接拖动音频块（整帧、可撤销），裁剪/音量/开始帧属性可用但未接撤销；独立大波形条和音量关键帧后续补。

## 里程碑 M3：文字排版与特殊工具（0.2.0）

记录时间：2026-11-08
版本：0.2.0（M3）

### 一句话状态

文字从「只能放一行字」升级为可排版的文本框系统：多行、换行宽高、行距、字距、内边距、加粗/斜体/下划线、文字描边、日式竖排与中文竖排；工作台新增「文本框」「特殊」两类工具（普通文本框、日式超绝硬直角、爆炸文本框、放射状线条、快速流过、漫画点阵），并补上自动保存、批量数据撤销和模板整表复制。

### 本里程碑完成

- **文字排版**：`TextStyle` + `TextBlock` 深模块，场景、素材库缩略图、对话框预览共用同一套测量与绘制；换行宽度/高度、行距、字距、内边距、对齐
- **气泡内接**：椭圆和云朵按各自形状的内接矩形放大气泡本体（椭圆 ×√2，云朵按 2.62 超椭圆计算），四角文字块不会顶穿轮廓；排版预览根据文字亮度自动选浅色/深色背景，深色字在暗色主题下可见
- **字形**：加粗、斜体、下划线、描边（颜色 + 粗细；按字形 alpha 生成外轮廓，横排/竖排都支持）
- **竖排**：逐字落格，列方向可从右到左（日式）或从左到右（中文），可设换行高度
- **文本框**（工作台「文本框」分类，`EntityType::ComicText` + `core/ComicBox`）：
  - 普通文本框：云朵 / 矩形 / 椭圆，都带可拖动尖角；尖角位置存相对坐标，画布上拖小圆点即可指向任意点，撤销一步回退
  - 日式超绝硬直角：直角矩形、无尖角，适合日式旁白框
  - 爆炸文本框：爆炸外形、无尖角
  - 填充色、边框色、边框粗细在属性面板「漫画框」和工作台创建页都可调
- **特殊工具**（工作台「特殊」分类，`core/LineDeco`）：
  - 放射状线条：楔形集中线，中心收尖外缘宽，角度/长度随机抖动，约 60% 的线条随机加粗 1.4×；随机速度（Hz）和整体旋转（°/s）可调
  - 快速流过：成组平行线按帧流动，方向/速度/间距/长度可调，用作背景运动感
  - 漫画点阵：旋转的网点网格，点径沿渐隐方向从实心过渡到空白；间距、最大点径、网格角度、渐隐角度、最小点比例、手绘抖动、随机种子、颜色可调，用作漫画阴影/半调背景。网点本身不动画（抖动按 seed 静态生成），首次绘制时栅格化为 `Entity::halftonePixmap`，之后按一张图绘制；参数变化才失效重建，播放时不再逐点绘制
- **自动保存**：默认开启、每 5 分钟一次，设置 → 常规可关闭或改间隔；QSaveFile 原子写入
- **性能监视**：视图 → 性能监视（Ctrl+Shift+P），状态栏滚动显示播放 FPS、帧耗时、场景/视口/时间轴/视频解码耗时与实体数；`core/PerfMonitor` 用指数滑动平均平滑数值，开关写入全局设置
- **渲染缓存**：`TextBlock` 缓存文字位图（含描边）、`ComicBox` 缓存气泡外形+文字整体位图、`Entity::halftonePixmap` 缓存点阵；参数变化才重建。修复了 SANY 工程 166s 处云朵气泡叠加大点阵时每帧重算贝塞尔轮廓导致的严重卡顿（视口绘制从约 40ms 降到约 5ms）
- **更换素材**：图片/视频/音频实体可右键或属性面板换源文件；弹出素材库选择器，只列出同类型的库素材（和 Mine-imator 的素材列表一致），也可以从「导入新文件…」走文件选择。位置、关键帧、配对音频保留，视频连配对音频一起换，整次替换一条撤销
- **复制粘贴实体**：Ctrl+C / Ctrl+V 复制整棵子树（含关键帧与配对音频），Ctrl+D 原地复制；粘贴为同级实体并自动选中，一条撤销
- **实体多选**：实体栏 Ctrl+点击切换、Shift+点击范围选择；右键「组成文件夹」把选中实体收进新文件夹（自动去掉已被其他选中项包含的子级），整次操作一条撤销
- **拖动多选**：按住任一已选中的行拖动，整组实体一起移动；拖到文件夹中间即移入，拖到行间按图层顺序插入。拖动不会清空多选（与 Mine-imator 一致），整次移动一条撤销
- **拖动关键帧**：时间轴上的关键帧可直接左右拖动；按 Mine-imator 的方式，拖动已选中的关键帧会平移整个选择（Shift 追加、Ctrl 取消），关键帧不会互相覆盖，松手一条撤销
- **文件夹 Gizmo**：文件夹在视口里有固定的 160px 局部包围盒，因此可以像普通实体一样显示坐标轴、旋转环和四角缩放手柄；移动/旋转/缩放文件夹时子级整体跟随，文件夹不参与吸附目标
- **播放头记忆**：每个工程文件在全局设置里记住上次的播放条帧（按路径哈希），关闭、手动保存、自动保存时写入，重新打开工程时恢复
- **数据与撤销**：`SetEntityDataMapCommand` 多字段一条撤销；尖角拖动命令自动合并；模板实例化整表复制 `data`；颜色键按名称后缀识别
- **素材库**：长文件名/路径中间省略，右侧栏不再被撑宽
- **串流**：默认 HTTP 局域网（`http://本机IP:8080/stream.ts`），H.264/H.265 软件与 VAAPI 硬编，画质档位，低延迟参数；RTP 保留
- **监视器临摹**：参考视频同步叠加、透明度可调

### 架构

- `core/TextStyle`、`core/TextBlock`：文字样式描述、排版实现与文字位图/描边缓存
- `core/ComicBox`：气泡外形 + 尖角几何（椭圆/矩形/云朵/爆炸）与整体位图缓存

## 里程碑 M4：MP4 导出（已完成）

记录时间：2026-11-08
版本：0.2.0（M4）

### 一句话状态

出片闭环打通：文件 → 导出视频（`Ctrl+E`），整画布或任意摄像机视角，H.264 MP4 + AAC 音频，实时预览窗，软件/VAAPI 硬件编码，带进度与取消。

### 实现

- `render/VideoExporter`：UI 线程逐帧渲染 → BGRA rawvideo 管道 → ffmpeg；音频预先分块混成 48 kHz 立体声 PCM，作为第二路输入编码 AAC 192k
- 编码器可选 `libx264`（CPU 多线程）或 `h264_vaapi`（检测到 `/dev/dri/renderD128` 与编码器时显示）；VAAPI 用 `format=nv12,hwupload` 上传帧，画质档位映射为 CQP
- 帧渲染由 `MainWindow` 传入回调：先 `VideoPlayer::update(frame, allowProxy=false)` 从原视频解码，再走 `CameraRenderer::renderCameraImage`，与监视器一致且不吃 960 宽预览代理
- `app/ExportProgressDialog`：导出期间实时显示最后一帧（约 12 fps 刷新）、帧进度、渲染吞吐（fps）和剩余时间（250 ms 滑动窗口平滑）；关窗等同取消
- 先写 `<输出>.part.mp4`，成功后改名；取消/失败删除临时文件，不覆盖已有成片
- `app/ExportDialog`：输出文件、分辨率（默认工程尺寸、锁定工程比例、自动取偶数）、视角（整画布/摄像机，默认活动摄像机）、CRF 档位、编码器、是否含音频；记住上次目录/画质/编码器/音频开关
- 渲染与编码通过管道重叠：渲染一帧就交给 ffmpeg，管道积压超过 16 MB 时暂停渲染等编码器

### 验证

- `--export-test`：320×180 / 24 fps 工程，红色矩形从左到右移动 + 绿色视频源 + 1 秒 440 Hz 音频；导出后解码首帧验证尺寸、矩形位置、视频颜色、背景色，解码音频验证非静音；检查预览信号和预览窗绘制；VAAPI 可用时再跑一次硬件编码并解码首帧；另测一次 30 秒导出并在 120 ms 时取消，确认无残留文件
- 本机 Intel VAAPI 实测通过；无硬件时自动跳过并只测软件编码
- 50 个离屏自检全部通过

- 文件夹是 `EntityType::Folder`：无实物、可嵌套、可折叠；实体栏按父级形成图层树
- 父级坐标：子级的 X/Y/旋转/缩放相对父级；渲染、命中测试、手柄和拖拽使用父级世界变换
- 时间轴支持拖拽排序、拖入文件夹、右键新建文件夹；收起状态只影响显示，不影响渲染
- 锁定/隐藏沿父级链生效：锁定文件夹下的子对象不可选中，隐藏文件夹下的子对象不渲染
- 透明度沿父级链相乘（`Project::effectiveOpacity`）；有效透明度为 0 的实体视为不存在：不渲染、不参与视口命中/吸附，视频不解码
- `Project::entity()` 使用 `QHash<EntityId,int>` id 索引，增删/移动/整表替换时维护；父级链检查用 64 层上限替代每实体 QSet 分配，大量实体时每帧只做 O(实体数×层级) 的轻量查表
- 摄像机：时间轴对象，活动摄像机、取景比例 5%–100%、旋转、关键帧；位置限制在画布内，旋转允许越界
- 自定义轴心（`rotPointX/Y`）：位置锚定轴心，改轴心自动补偿位置，旋转围绕轴心
- 锁定在数据层强制：值、关键帧不可改；锁定后自动取消选择，视口和时间轴都不能再选中

### 动画与时间轴

- 特殊工具的数据都存在 `Entity::data` 里，颜色键沿用 `color/fill/stroke`（判定改为按后缀匹配，新颜色键不用再登记）
- 时间轴：固定缩放 + 横向滚动 + 自动跟随播放头

- 关键帧可以 `Delete` 删除，撤销恢复
- 时间轴左侧搜索框过滤对象

### 摄像机与监视器

- 工作台「摄像机」类型，只填名称；创建即选中并设为活动摄像机；没有摄像机时监视器显示工作摄像机
- 视口只显示活动摄像机取景框；框外 55% 深灰半透明压暗，框内点击穿透给实体；视图菜单可隐藏取景框
- 拖动边框/标题条移动，四角中心固定缩放，顶边旋转手柄；移动吸附沿用画布/实体，旋转沿用角度吸附
- 活动摄像机 ID 和监视器视图存进工程；监视器位置/大小/画质/独立窗几何存全局设置
- 监视器下拉：工作摄像机 / 场景摄像机 / 整画布；无辅助线、无选中框，等比黑边。工作摄像机沿用视口取景但裁剪到画布多边形，画布外对象不会漏进预览
- 监视器标题栏显示帧率：静止时项目帧率，播放时每秒统计实际刷新率；低于项目帧率时变红
- 草稿默认按监视器分辨率并使用缩略图；高质量按项目分辨率并使用原图；播放强制草稿，暂停恢复
- 画布内显示项目背景，画布外纯黑；工作摄像机显示主视口原始内容（包括画布外）
- OBS 式独立窗口：按钮或拖出主窗口；关闭独立窗口停靠回右下角；默认不置顶，可切换「置顶」
- 共享 `SceneRenderer` / `CameraRenderer`，主视口、监视器、未来 MP4 导出共用
- 摄像机可以作为父级：台标/新闻条按镜头空间定位；摄像机视图会抵消镜头父级变换，所以它们在监视器里固定位置和大小
- 摄像机也可以作为子级挂到文件夹/实体下跟随移动；`Camera::state` 组合父级位移/旋转/缩放；挂父级后暂停画框直接拖动，改属性 X/Y/旋转/取景比例
- 摄像机不能作为另一个摄像机的子级；父级非均匀缩放时取景框用平均缩放近似
- **临摹参考**：监视器标题栏「临摹」菜单导入视频；独立临时 Project + VideoPlayer 按项目帧解码，叠在监视器画面上，透明度 0–100%，支持清除；参考视频使用同一代理缓存
- **图层顺序修复**：时间轴列表自上而下 = 画面前到后；主视口、监视器、串流统一按列表反向绘制（最后一行先画、第一行最后画），命中测试从第一行（最前）开始。之前主视口按存储序绘制、渲染器正向绘制，导致列表底部的图形反而遮住上面的图形
- **时间轴滚动**：实体多时右侧出现垂直滚动条，滚轮上下滚动实体列表（每格 4 行），Shift+滚轮左右滚动时间轴（每格 120px），Ctrl+滚轮以鼠标为锚点缩放（0.25–32 px/帧）；垂直滚动会同步行位置与时间轴刻度
- **单属性关键帧**：属性面板每行右侧有 ◇ / ◆ 按钮，点一下只给该属性在当前帧打关键帧（◆ 表示已有关键帧，再点删除）；添加/删除都进撤销栈，避免“以为给透明度打了帧其实没有”的情况
- **HTTP 串流（默认）**：监视器标题栏「串流」菜单启动 ffmpeg 原始帧管道，编码后输出 MPEG-TS 到 stdout；`QTcpServer` 在 8080–8089 选择端口并用 `http://<本机IP>:<port>/stream.ts` 提供流，手机 VLC 直接打开本机 IP；菜单可复制地址、列出所有本机 IPv4
- **画质/编码**：流畅 640/2.5M、标准 960/5M（默认）、高清 1280/8M；H.264/H.265 软件编码，检测到 `/dev/dri/renderD128` 时提供 H.264/H.265 VAAPI 硬件编码。H.265 需要手机 VLC 支持 HEVC
- **RTP 串流**：同一管道可切换为 RTP/MPEG-TS 组播到 `239.255.42.99:5004`；手机 VLC 打开 `rtp://@239.255.42.99:5004`；组播地址不是本机 IP
- 串流时停靠监视器固定为标题栏高度，停止后恢复几何；分辨率长边按画质档位，帧率取项目帧率并限制 10–30；只传画面，不传项目音频
- 原始 RGBA 帧按整帧写入 ffmpeg stdin；缓冲区不够时丢弃整帧而不是写半帧，避免宏块错位/花屏
- 低延迟：mpegts 输出 `-muxdelay 0 -muxpreload 0 -flush_packets 1`，HTTP 客户端 socket 开 TCP_NODELAY 并每块 flush；软件 H.264 用 zerolatency/veryfast，VAAPI 用 `-bf 0 -async_depth 1`
- VLC 端仍默认缓存约 1 秒；手机 VLC 的网络缓存需调到 0–200 ms。串流帧率跟随项目帧率（10–30），低帧率项目本身就会显得不流畅

### 文件夹与父级

- `EntityType::Folder` 是无实物实体，只提供层级和坐标变换；可嵌套
- `Entity::parent` 指向父级，`kInvalidEntity` 表示工作台世界坐标
- 图层顺序由 `Project::entityOrder()` 按父级做前序遍历；渲染和命中测试使用同一顺序，保证图层前后关系一致
- 时间轴实体栏按层级缩进，文件夹行有展开/收起三角；收起只影响显示
- 支持拖动实体行排序、拖到文件夹行中间移入文件夹、右键新建文件夹/子文件夹/同级文件夹
- 属性面板「父级」下拉框列出工作台和所有可用实体（排除自身与后代），修改走 `SetParentCommand`
- 父级变换沿链组合：`world = childLocal * parentLocal * ...`；子级的 X/Y/旋转/缩放是相对父级的；摄像机父级使用 `Camera::state`，子级在镜头空间定位于画面
- 缩放/移动父级时子级一起变换；隐藏/锁定沿父级链生效（隐藏不渲染，锁定不可选中）
- 移动/父级修改/新建文件夹均接入撤销栈；删除有子对象的父级会被阻止

### 视频播放

- 每个视频实体维护一个 FFmpeg 解码器（`VideoPlayer`）；播放头移动和播放时按项目帧取帧
- 顺序播放连续解码前进；后退或跳转超过 1 秒时 seek 到前一个关键帧再解码到目标
- 项目帧率高于视频帧率时保持当前帧到显示区间结束，避免每 tick 回退 seek
- 解码结果写入 `Entity::image` 并清空缩略图/Pixmap 缓存，主视口和监视器共用
- 视频当前帧和音频均为 FFmpeg 软件解码；Qt Multimedia 硬件视频解码尚未接入
- 1080p H.264 顺序播放的软件解码开销在本机约 2–3ms/帧，实时播放有余量
- **预览代理**：原视频关键帧间隔约 8 秒，随机 seek 平均约 160ms；后台用 ffmpeg 转成 960 宽、15 帧 GOP、CRF 27、无音轨的代理，随机 seek 约 3ms；140 秒 1080p 视频约 5 秒生成、约 37MB，缓存在 `~/.cache/PVForge/proxies`
- 代理生成在后台排队（一次一个 ffmpeg 进程，4 线程）；完成后自动切换解码路径并刷新当前帧；ffmpeg 缺失或生成失败时回退原视频
- `sourceWidth`/`sourceHeight` 保存原始视频尺寸，代理只替换像素数据，不改变实体在画布上的大小
- 播放头超过视频 `duration` 后清空画面，不保留最后一帧；回到范围内重新解码
- 导入带音轨的视频时，后台同时解码默认音轨：素材库得到视频和「· 音频」两个素材
- 从视频素材创建实体时自动创建配对的音频实体（`pairedVideo` 记录关系）；保存/加载后仍保留配对信息

### 音频与波形

- 音频是时间轴对象：时间轴开始、裁掉开头/结尾、音量、淡入淡出；字段右侧「取」按钮直接取播放头位置；在时间轴上按住波形块可直接拖动音频（整帧、可撤销）；裁掉开头/结尾时保留的波形保持原位，不会跳到第 0 帧
- 属性面板的音量、淡入、淡出、裁掉开头 / 结尾、开始帧都走撤销栈；同一字段连续编辑合并为一条，不同字段不互相合并；「取」裁剪同时改开始帧与裁剪值，也一条撤销
- 独立大波形页：每个音频对象一行，Ctrl+滚轮缩放、滚轮 / Shift+滚轮滚动、点击定位播放头
- FFmpeg 系统包解码（含 FLAC/OGG/Opus 等），统一为 48kHz 立体声 int16
- 1ms 峰值包络；时间轴音频行按波形峰值绘制，音频行高 56px
- 工作台「媒体」和素材库支持导入音频；波形缩略图进素材库
- Qt Multimedia `QAudioSink` 播放；多音频混音、裁剪、音量、淡入淡出
- 有音频时以音频播放位置驱动动画播放头
- 拖动播放头/逐帧时播放 150ms 短片段（音频擦洗），视图菜单可关闭；默认开启
- PCM/波形是运行时缓存，工程只存哈希路径和参数

- 时间轴和视口配色跟随系统主题，图标优先用桌面图标主题；缓动缩略图和贝塞尔图表用 QPalette 自绘，暗色已验证
- 设置页：qBittorrent 式左侧分类 + 右侧内容页（常规、编辑器、新项目、时间轴、素材、解码、关于）；常规页可调自动保存开关和间隔（默认开启、5 分钟）；关于页显示系统/CPU/内存/显卡/显示器/Qt/FFmpeg 与当前解码路径，可一键复制；帮助菜单的「关于 PVForge」也打开该页
- 语言文件 `assets/lang/zh_CN.json` / `en_US.json`（核心界面）

## 架构

```
src/
├─ core/     Project/Entity（父级/文件夹）/Track/Keyframe、History+Commands、Settings、Lang、VectorShape、Camera、Easing
├─ anim/     （预留）
├─ render/   SceneRenderer（共享实体绘制）、CameraRenderer（场景/工作摄像机取景）、VideoExporter（逐帧渲染 → ffmpeg MP4）
├─ media/    VideoDecoder（FFmpeg 首帧）、VideoPlayer（按播放头解码当前帧）、VideoProxy（后台预览代理）、AudioDecoder/AudioClip（音频解码与波形）、MediaImporter、DecoderInfo
├─ audio/    AudioEngine（离线混音 + QAudioSink 播放）
├─ ui/       Viewport、TimelinePanel、CurveEditor、WaveformView、PropertiesPanel、AssetLibraryPanel、
│            ProjectPropertiesPanel、EnvironmentPanel、WorkbenchPanel、
│            CameraMonitor、EasingPicker、BezierEditorDialog、CollapsibleSection
└─ app/      MainWindow、WelcomeWindow、NewProjectDialog、SettingsDialog、ExportDialog、ExportProgressDialog、SystemInfo、AppIcon
```

关键设计：

- **位置 = 轴心**：变换 `T(pos) · R · T(-pivot) · S`，改轴心补偿位置，视觉不动
- **摄像机 = 画布内的旋转取景框**：位置/缩放/旋转复用实体轨道；未旋转框限制在画布内，旋转可越界，画布外纯黑
- **共享渲染器**：主视口、监视器、未来导出都走 `SceneRenderer`；辅助线和压暗只留在主视口
- **内容寻址素材**：哈希文件名 + 原始显示名
- **命令历史**：复合命令 + 合并，一次拖动一条撤销
- **缓动归属目标关键帧**：设置到达 1s 的曲线，就改 0s → 1s 这一段；和 Mine-imator 的“出发段”模型相反，目的是符合“到这个姿势”的直觉
- **异步导入**：重活在工作线程，主线程入库
- **解码策略**：视频当前帧和音频全部走 FFmpeg 软件解码；启动时禁用 Qt Multimedia 硬件视频后端，避免 VDPAU/VAAPI 探测；硬件解码后续再评估
- **音频主时钟**：有音频时播放头跟随 `QAudioSink` 实际播放位置；无音频才用计时器
- **求值/渲染未分离**：渲染器仍逐帧读 Project；导出直接复用这套路径，在 UI 线程逐帧渲染并推给 ffmpeg，暂不需要 FrameSnapshot

## 已知限制

- 导出可用 `libx264` 软件编码或 VAAPI 硬件编码；VAAPI 需要 Intel/AMD GPU 与可读的 `/dev/dri/renderD128`，硬件档位用 QP 近似 CRF，画质与软件编码不是逐像素等价
- 暂不支持分段导出
- 漫画文本框的尖角是整体相对坐标，缩放实体时尖角跟着缩放；暂时不能在画布上新增第二个尖角
- 视频内嵌音轨按默认音轨自动提取；多音轨、字幕轨暂不处理
- 自动保存只处理已有路径的工程；未命名的新工程请先手动保存一次
- 无频谱可视化对象（音频轨波形已支持）
- 父级坐标作用于可视实体；摄像机可以作为父级，也可以挂到文件夹或实体下；音频没有空间坐标
- 摄像机不能作为另一个摄像机的子级；挂到父级后画框拖动暂停，改属性 X/Y/旋转/取景比例
- 父级非均匀缩放时，摄像机取景框用平均缩放近似
- 监视器串流只有画面，没有项目音频；HTTP 端口 8080–8089 需放行，手机和电脑需在同一局域网
- RTP 模式使用组播地址，部分 Wi-Fi/路由器会屏蔽；默认 HTTP 模式没有这个问题
- 临摹参考从项目第 0 帧开始同步，暂不支持单独偏移
- 删除有子对象的父级前需要先把子对象拖到工作台或删除
- 音频属性修改（音量、淡入、淡出、裁掉开头 / 结尾、开始帧）已接入撤销栈，同一字段连续编辑合并为一条；时间轴拖动音频也一条撤销
- 音频擦洗是短片段预览，不是变速连续擦洗
- 音频大波形页使用 1ms 峰值，暂未做卡点标记；没有频谱可视化对象
- 音频工程加载时同步解码；长音频可能卡一下
- 图表页只显示当前选中实体的属性曲线，不能把多个实体的曲线叠在一起；关键帧选择以整帧为单位，同一帧的所有属性一起移动
- 贝塞尔手柄只对已经是贝塞尔的进入段显示，预设缓动需要先右键「转为贝塞尔」
- 旋转实体的角缩放仍围绕中心
- 实体单选（框选只作用于关键帧）
- 英文翻译只覆盖核心界面
- 摄像机不支持自定义输出分辨率/宽高比（竖屏裁切）；监视器没有无边框全屏投影
- 3D 世界/Minecraft 资产完全移除（有意）
