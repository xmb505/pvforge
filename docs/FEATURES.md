# PVForge 功能详情

README 只保留概览；这里记录完整的功能清单、交互细节和实现行为。构建与快速开始见 [README](../README.md)。

## 时间轴与关键帧

- **时间轴**：动画长度跟随素材和关键帧；逐属性关键帧、自动关键帧、播放/循环
- **帧精确刻度**：秒模式按项目帧率均分（24 fps 一秒 24 格，可降到 12/8/6/4…），帧模式只显示帧号
- **单帧步进**：点刻度行后轻按 `←` / `→` 走一帧，按住约 0.4 秒连续播放/倒退
- **关键帧缓动**：曲线属于**到达的关键帧**（例如设置 1s 的曲线 = 0→1s 这一段），右键关键帧或属性面板「缓动」按钮打开视觉模板网格；自定义三次贝塞尔可拖手柄
- **拖动关键帧**：关键帧可以左右拖动，已选中的关键帧整体平移（Shift 追加、Ctrl 取消选择），松手一条撤销
- **图表页**：时间轴区域的「图表」页把当前选中实体的 X / Y / 旋转 / 缩放 X / 缩放 Y / 透明度画成可叠加曲线；曲线用与渲染相同的 `Track::evaluate` 采样，颜色跟随调色板明度。关键帧可整帧拖动、整组平移，目标帧有键时自动停在前一格；贝塞尔进入段露出可拖手柄（预设缓动可右键「转为贝塞尔」）；支持框选、Ctrl+C / Ctrl+V、批量缓动、删除和全选，松手一条撤销
- **波形页**：时间轴区域的「波形」页为每个音频对象显示一行大波形，Ctrl+滚轮缩放、滚轮 / Shift+滚轮滚动、点击定位播放头；卡点标记和频谱对象待后续
- **选关键帧**：点击关键帧菱形会选中并把播放头移到该关键帧，属性面板显示该关键帧的数值

## 实体与图层

- **实体**：图片、视频（逐帧播放，内嵌音轨自动拆成音频）、文字、矢量（9 种形状）
- **文件夹与父级**：时间轴实体栏是图层树，可新建文件夹、拖拽排序/拖进文件夹、点箭头收起；属性面板「父级」可选工作台或任意实体，子级坐标跟随父级
- **文件夹 Gizmo**：文件夹也有轴心/坐标轴/旋转环/缩放手柄，移动、旋转、缩放文件夹时子级整体跟随
- **锁定**：锁定实体不能在视口或时间轴上选中；锁定当前对象会立即取消选择，用时间轴行的锁按钮解锁
- **多选**：实体栏 Ctrl+点击切换、Shift+点击连选；右键「组成文件夹」把选中的实体收进新文件夹
- **拖动多选**：按住任一已选中的行拖到文件夹上，整组实体一起移入；拖到两行之间按图层插入，一条撤销
- **复制粘贴**：Ctrl+C / Ctrl+V 复制整棵子树（含关键帧和配对音频），Ctrl+D 原地复制
- **更换素材**：图片/视频/音频实体可以换源文件，弹出素材库选择（或导入新文件），位置、关键帧、配对音频都保留，一条撤销
- **透明度优化**：实体（含父级文件夹）有效透明度为 0 时视为不存在——不渲染、不参与视口点击/吸附，视频也不解码；实体查找走 id 索引

## 视口与摄像机

- **视口交互**：选中框、四角缩放、X/Y gizmo、旋转环、自定义轴心、PPT 式角缩放
- **吸附**：画布边缘/中心、其他实体、边缘中点（可选）、旋转角度吸附，青色参考线；`Shift` 等比缩放时按旋转后的可视包围盒吸附
- **摄像机**：时间轴对象，位置/取景比例/旋转关键帧；取景框外压暗，框内点击穿透；摄像机可作为父级，让台标/新闻条在镜头画面内固定；也可挂到实体或文件夹下跟随移动

## 监视器

- **视图**：工作摄像机 / 场景摄像机 / 整画布；工作摄像机沿用视口取景，但只显示画布内的内容，画布外对象不会漏进监视器
- **画质**：草稿缩略图、高质量原图；无辅助线、等比黑边
- **标题栏**：显示帧率（播放时显示实际刷新率）
- **OBS 式弹出**：监视器可拖出为独立窗口，关闭停靠回视口，可置顶
- **临摹**：小监视器「临摹」菜单导入参考视频，按播放头同步叠在画面上，透明度可调，用于描改 PV；可一键清除

## 文字与漫画

- **文字排版**：文字和文本框共用一套排版模块（换行宽度/高度、行距、字距、内边距、对齐、加粗/斜体/下划线、文字描边颜色/粗细、多行内容、竖排可切从右到左或从左到右）；工作台和属性面板都有「排版…」对话框，右侧实时预览与画布完全一致
- **文本框**：工作台「文本框」分类——普通文本框（外形可切云朵 / 矩形 / 椭圆，尖角可在画布上直接拖动、指向任意点）、日式超绝硬直角（无尖角）、爆炸文本框；三者共用文字排版对话框。椭圆和云朵按内接矩形自动放大，四角文字不会顶到轮廓；排版预览会根据文字颜色自动换浅色/深色底
- **渲染缓存**：文字、气泡外形+文字、漫画点阵都按参数栅格化缓存，参数不变时每帧只画一张位图；大点阵叠在云朵气泡上的卡顿已消除

## 特殊工具

工作台「特殊」分类：

- **放射状线条**：楔形集中线，角度抖动 + 随机加粗，速度可调，手绘感
- **快速流过**：一组平行线按帧流动，做背景运动感
- **漫画点阵**：旋转网点，点径沿渐隐方向变化，可调间距/最小点比例/手绘抖动，做漫画阴影和半调背景；图案只栅格化一次，之后按图片缓存，抖动是静态的，播放时不重绘网点
- **品牌瓷砖墙**：新闻发布会式棋盘格，可加任意多组 Logo，每组单独配色，密度按列×行设置，间距/透明度可调；Logo 支持 PNG/JPG/SVG，SVG 会按 1024px 长边栅格化避免糊

## 音频与视频

- **音轨**：音频对象、时间轴 56px 波形行、时间轴内直接拖动音频块（整帧、可撤销）、裁剪/音量/淡入淡出/开始帧、FFmpeg 解码、Qt Multimedia 播放与音频主时钟、拖动/逐帧音频擦洗
- **音频撤销**：属性面板的音量、淡入、淡出、裁剪（trimStart/trimEnd）和开始帧全部接入撤销栈；同一字段连续编辑合并为一条，「取」按钮裁剪也一条撤销
- **大波形页**：时间轴「波形」页每个音频对象一行，Ctrl+滚轮缩放、滚轮 / Shift+滚轮滚动、点击定位播放头
- **视频音轨**：导入带音轨的视频时，素材库同时生成视频和「· 音频」两个素材；从视频素材创建实体时同时生成配对的音频对象
- **视频预览代理**：导入后在后台生成 960 宽、0.5 秒 GOP 的预览文件，缓存到 `~/.cache/PVForge/proxies`；时间轴随机 seek 从约 160ms 降到约 3ms
- **解码信息**：设置→解码显示解码方式（当前固定为软件解码）和实际使用的 FFmpeg / Qt Multimedia 路径

## 导出

- **入口**：文件 → 导出视频…（`Ctrl+E`）
- **视角**：整画布，或工程里的任意摄像机；默认选中活动摄像机
- **参数**：输出分辨率（可一键回到工程尺寸，宽高锁定工程比例、自动取偶数）、项目帧率、H.264 画质档位（CRF 18/21/25/28）
- **预览窗**：导出时实时显示正在渲染的画面，底部显示帧进度、渲染吞吐（fps）和预估剩余时间；可直接在预览窗取消
- **编码器**：默认 `libx264` 软件编码（ffmpeg 多线程，自动使用多核）；检测到 `/dev/dri/renderD128` 和 `h264_vaapi` 时可切 VAAPI 硬件编码，画质档位用 QP 近似 CRF
- **音频**：默认混入工程音频，48 kHz 立体声 AAC 192 kbps；没有音频或全静音时自动只出画面
- **画面**：逐帧复用 `SceneRenderer` / `CameraRenderer`，与监视器所见一致；视频实体在导出时从原文件按源分辨率解码，不使用 960 宽预览代理
- **流水线**：渲染在 UI 线程逐帧进行，ffmpeg 在自己的进程里并行编码；通过 raw 管道重叠，渲染与编码同时跑
- **进度与取消**：模态进度条显示已渲染帧数；编码阶段可继续取消，取消或失败不会留下半截 MP4（先写 `.part.mp4`，成功后才改名）
- **时长**：导出从第 0 帧到最后关键帧/素材结尾；完全空白的时间轴导出 2 秒静帧
- **封装**：`yuv420p`、`-movflags +faststart`，输出可直接上传

## 工程与系统

- **工程**：关闭未保存提示、相对路径素材、可选打包进工程目录
- **素材库**：异步导入、内容寻址去重、搜索、预览、复用；长文件名/长路径中间省略，悬停看完整内容
- **自动保存**：默认每 5 分钟自动保存一次已有路径的工程；设置 → 常规可关闭或修改间隔
- **播放头记忆**：退出或保存工程时记住当前帧，重新打开工程自动回到上次的播放条位置
- **撤销/重做**：移动、缩放、轴心、旋转、摄像机拖动均合并为一条撤销
- **主题**：自绘图标和缓动曲线使用 QPalette 颜色，跟随 Breeze 等系统主题，暗色下已验证
- **性能监视**：视图 → 性能监视（Ctrl+Shift+P），状态栏实时显示播放 FPS、每帧耗时、场景/视口/时间轴/视频解码耗时和实体数，开关状态会记住
- **关于页**：设置→关于显示系统、CPU、内存、显卡、显示器和 Qt/FFmpeg 版本，可一键复制；帮助菜单的「关于 PVForge」也打开此页

## 工程格式

- `.pvproj` 是 JSON：实体、关键帧、摄像机、活动摄像机、监视器视图都在里面
- 素材按内容哈希存为 `assets/<sha256>.<ext>`，天然去重，显示名另存
- 工程目录内的素材用相对路径，移动工程不丢素材
- 可在素材菜单开启「全部打包到项目」，或手动「立即打包所有素材」
- 时间轴不设固定时长：长度由素材时长和最后一个关键帧决定

## 实体类型

| 类型 | 能力 |
|---|---|
| 图片 | PNG/JPG/WebP/BMP，导入后按画布比例适配 |
| 视频 | MP4/WebM/MOV/MKV，FFmpeg 软件解码；拖动播放头或播放时更新当前帧；带音轨时同时生成音频素材；超过时长后不显示画面 |
| 文字 | 内容、字体、字号、颜色、对齐、描边，创建后属性面板可继续改 |
| 矢量 | 矩形/圆角矩形/椭圆/直线/三角形/心形/星形/多边形/箭头 |
| 摄像机 | 取景框对象；位置/取景比例/旋转可打关键帧，5%–100%，画布内限制 |
| 音频 | WAV/MP3/FLAC/OGG/M4A 等；时间轴波形、拖动移动、开始帧、裁剪、音量 |

## 已知限制

完整清单见 [MILESTONE.md](MILESTONE.md)。主要的：

- 导出可用 `libx264` 软件编码或 VAAPI 硬件编码；VAAPI 需要 Intel/AMD GPU 与可读的 `/dev/dri/renderD128`，硬件档位用 QP 近似 CRF，画质与软件编码不是逐像素等价
- 暂不支持分段导出
- 视频内嵌音轨按默认音轨自动提取；多音轨、字幕轨暂不处理
- 自动保存只处理已有路径的工程；未命名的新工程请先手动保存一次
- 无频谱可视化对象
- 图表页只显示当前选中实体，关键帧按整帧选择和移动；波形页暂无卡点标记
- 视频帧和音频均为 FFmpeg 软件解码；Qt Multimedia 硬件视频解码尚未接入
- 预览使用 960 宽代理；导出时视频从原文件按源分辨率解码
