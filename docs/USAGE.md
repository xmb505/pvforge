# PVForge 操作手册

更完整的功能说明见 [FEATURES.md](FEATURES.md)，构建与安装见 [README](../README.md)。

## 日常操作

| 操作 | 方式 |
|---|---|
| 新建/打开项目 | 启动欢迎页；项目内 `Ctrl+S` 保存 |
| 右侧页签 | 默认「项目属性」；选中实体时出现以实体名命名的属性页签 |
| 打开工作台 | 视口左上角立方体按钮 |
| 创建工作台实体 | 左侧选类型，右侧填参数，点「创建」 |
| 关闭工作台 | 点击浮层外部、Esc，或再点立方体按钮 |
| 移动实体 | 左键拖动（自动在当前帧打帧） |
| 改变换/透明度 | 右侧属性面板（自动打帧） |
| 显式打全属性关键帧 | 属性面板「在当前帧打关键帧」 |
| 删除场景实体 | 选中后按 `Delete`，或编辑菜单「删除实体」 |
| 删除选中关键帧 | 时间轴里选中关键帧后按 `Delete` |
| 重命名实体 | 双击时间轴左侧的名字 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 拖播放头 | 在刻度行按住左右拖 |
| 逐帧前进 / 后退 | 点一下刻度行后，轻按 `←` / `→` 走一帧；按住约 0.4 秒后按帧率连续播放 / 倒退 |
| 时间轴刻度单位 | 点时间轴左上角的「秒 / 帧」按钮，或视图菜单切换 |
| 时间轴滚动 | 滚轮上下滚动实体列表，Shift+滚轮左右滚动时间，Ctrl+滚轮缩放；右侧有垂直滚动条 |
| 查看解码器 | 设置 → 解码；可复制当前 FFmpeg / Qt Multimedia 路径 |
| 查看硬件信息 | 设置 → 关于；显示 CPU、内存、显卡、系统版本，可复制全部信息 |
| 自动保存 | 设置 → 常规 → 保存；默认开启，每 5 分钟一次，只保存已有路径的工程 |
| 改文字排版 | 工作台文字页或属性面板「文字」区点「排版…」：换行宽度/高度、行距、字距、内边距、对齐、字形、描边颜色/粗细、竖排方向 |
| 加文本框 | 工作台 → 文本框：普通文本框 / 日式超绝硬直角 / 爆炸文本框；普通文本框选中后拖画面小圆点改尖角 |
| 多选实体 | 实体名 Ctrl+点击切换选择，Shift+点击连续选择；右键「组成文件夹」；拖动任一选中行可整组移动 / 拖进文件夹 |
| 拖动关键帧 | 时间轴上拖动关键帧；Shift 追加选择，Ctrl 取消选择，整组平移后一条撤销 |
| 透明物体 | 属性面板把透明度调到 0；画布不再绘制、点击会穿透到后面的物体，视频停止解码 |
| 复制实体 | 选中实体 Ctrl+C，Ctrl+V 粘贴；Ctrl+D 原地复制；右键时间轴也可 |
| 更换素材 | 右键时间轴里的图片/视频/音频实体 → 更换素材…，或属性面板「素材」区的按钮；从素材库选同类型素材，或导入新文件 |
| 漫画点阵 | 工作台 → 特殊 → 漫画点阵：范围、点间距、最大点径、网格角度、渐隐角度、最小点比例、抖动、颜色；创建后属性面板可继续调 |
| 品牌瓷砖墙 | 工作台 → 特殊 → 品牌瓷砖墙 → 配置：任意添加 Logo 组、每组配色、密度（列×行）与间距；创建后属性面板可再次编辑 |
| 跳转播放头 | 点击轨道空白处 |
| 选关键帧 | 点击关键帧菱形：选中并把播放头移到该关键帧，属性面板显示该关键帧的数值 |
| 给单个属性打关键帧 | 属性面板每行右侧的 ◇ 按钮；当前帧已有关键帧时显示 ◆，再点删除 |
| 改关键帧缓动 | 右键关键帧，或选中实体后在属性面板「关键帧」里点「缓动：…」；选「自定义」拖贝塞尔手柄 |
| 框选关键帧 | 在轨道区拖动出选框 |
| 悬停对象行 | 行尾出现隐藏 / 锁定 / 全选关键帧按钮 |
| 新建文件夹 | 右键时间轴实体行：新建文件夹 / 在此文件夹内新建文件夹 |
| 图层排序 | 拖动实体名上下移动；列表最上面 = 画面最前，新实体落在列表底部（最后），拖上去就提前；拖到文件夹行中间放入文件夹 |
| 收起文件夹 | 点文件夹名前的三角；再点展开 |
| 父级坐标系 | 属性面板「父级」选工作台或任意实体；X/Y/旋转/缩放相对父级 |
| 摄像机作为父级 | 选中台标/文字，父级选摄像机；监视器里固定在画面位置，镜头缩放旋转时不跑位 |
| 摄像机跟随实体 | 选中摄像机，父级选文件夹/实体；摄像机只读跟随，画框拖动暂停，改属性 X/Y/旋转/取景比例 |
| 临摹参考 | 监视器「临摹」→ 导入临摹视频；拖动透明度；按播放头同步叠加 |
| 手机当副屏 | 监视器「串流」→ 开始串流；默认 HTTP 960p/5Mbps H.264，手机 VLC 打开 `http://本机IP:8080/stream.ts`；可切 H.265/VAAPI 硬编和 RTP |
| 锁定 / 解锁 | 点时间轴行的锁按钮；锁定后自动取消选择，画布和时间轴都不能再选中 |
| 播放/暂停 | `空格` |
| 视口缩放/平移 | 滚轮 / 中键拖动 |
| 时间轴缩放 | `Ctrl+滚轮` |
| 创建摄像机 | 工作台选「摄像机」，填名字（可留空），创建后自动选中并激活 |
| 导入音频 | 工作台「媒体」或素材库导入 WAV/MP3/FLAC/OGG/M4A 等 |
| 导入带音轨的视频 | 自动生成视频和「· 音频」两个素材；从视频素材创建实体时同时生成配对音频 |
| 调整音频 | 属性面板「音频」设置时间轴开始、裁掉开头/结尾、音量；字段右侧「取」按钮直接取播放头位置 |
| 裁剪音频 | 播放头放到要保留的边界，点「裁掉开头/结尾」的「取」；剩余波形保持原位，不跳到第 0 帧 |
| 移动音频 | 在时间轴上按住音频波形块左右拖动；按整帧对齐，可撤销 |
| 等比缩放 | 按住 `Shift` 拖四角，围绕轴心等比缩放并吸附画布/实体；`Ctrl` 临时关闭吸附 |
| 铺满画布 | 16:9 素材在 16:9 工程里，`Shift` 把角拖到画布角即可吸附铺满 |
| 拖动/逐帧试听 | 默认开启；视图菜单「音频擦洗」可关闭；播放头移动时播 150ms 短片段 |
| 调整取景框 | 拖边框或标题条移动；拖四角以中心缩放；拖顶边圆点旋转 |
| 切换活动摄像机 | 时间轴选中摄像机，或监视器标题栏下拉 |
| 摄像机监视器 | 视口右下角；标题栏切草稿/高质量、弹出、关闭；拖标题条左侧点阵移出窗口 |
| 导出 MP4 | 文件 → 导出视频…（`Ctrl+E`）：选输出文件、分辨率、视角（整画布/摄像机）、画质，点「导出」；进度条可取消 |

## 工作流建议

1. 先建项目，确定分辨率与帧率
2. 用素材库导入图片/视频/音频，再到工作台创建实体
3. 先摆构图和摄像机，再打关键帧
4. 用监视器检查最终画面，必要时弹出到副屏
5. 拉长或检查时间轴到最后一个关键帧/音频结尾，文件 → 导出视频… 出片
6. 打开性能监视（`Ctrl+Shift+P`）观察播放开销；帧耗时接近帧间隔时先简化场景

## 已知限制

完整清单见 [MILESTONE.md](MILESTONE.md) 的「已知限制」。当前最需要注意的是：导出是 CPU 软件编码，长工程会编一会儿；长音频工程加载时会同步解码，视频预览代理未生成完时随机拖动可能卡。
