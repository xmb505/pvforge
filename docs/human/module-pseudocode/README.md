# 模块伪代码

本目录放**人类手写**的模块伪代码、数据结构和不变量。不是现状记录，而是“应该怎么实现”。

约定：

- 一个模块一个文件，例如 `workbench-cache.md`、`solver-spiral.md`、`timeline-rows.md`。
- 新文件从 [`../SPEC_TEMPLATE.md`](../SPEC_TEMPLATE.md) 复制。
- 至少写清：输入/输出、数据结构、伪代码、不变量、错误处理、验收、禁止事项。
- 与代码冲突时视为漂移；AI 必须报告差异，不能自行改本目录来“对齐实现”。

AI/Agent 规则：

- 动某个模块前，先读这里对应的 `.md`。
- 没有对应文件时，不要自己补写“应该是这样”；可以提出草案，但必须由人类确认后才能放进本目录。
- 本目录优先级高于 `docs/AI/`，与 `docs/human/README.md` 的规则一致。

模块索引由人类维护；AI 不要擅自增删条目。
