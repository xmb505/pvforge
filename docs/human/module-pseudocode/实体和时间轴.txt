实体和时间轴上的片段一一对应

实体有各种属性：UUID / 名字（可以重复）/ 开始帧 / 结束帧 / 坐标系 / 工作台可见性 / 渲染可见性 / 缩放参数 / 实体类型 / 父实体区间跟随（这个为true的时候，父实体的时长和子实体一样） / 素材贴图 / 拓展参数（各种我没想到的参数）

实体在json里面要可以像文件夹一样，实体包裹实体，并且需要一个验证器来校验子实体的持续帧区间，必须为父实体的子集

简单来说：开了父实体区间跟随的子实体，父实体随便拉，他的时长一样拉

父实体原本0-10帧，子实体1-5帧，子实体在3帧有个关键帧
子实体启用区间跟随后，子实体变为0-10帧，3帧有个关键帧
父实体往左移动10帧，变成10-20帧，子实体在绝对帧13帧有个关键帧
用户拖动父实体的开始条，从10调整的15.子实体的13帧关键帧丢失（用户拖到15并放手那一刻）
