# 代理与翻墙

Agent 需要访问 GitHub / 外网时，优先使用下面这些**本机或内网**代理：

| 用途 | 地址 | 协议 |
|---|---|---|
| 本机代理 | `127.0.0.1:7897` | HTTP / SOCKS5 |
| 内网代理 | `192.168.1.112:7897` | SOCKS5 |

用法：

```bash
export HTTPS_PROXY=http://127.0.0.1:7897
export HTTP_PROXY=http://127.0.0.1:7897
# 或 SOCKS5：
# export HTTPS_PROXY=socks5h://127.0.0.1:7897
```

`git`、`gh`、`curl` 都会继承这些环境变量。

规则：

- 代理不可用时先试 `127.0.0.1:7897`，再试 `192.168.1.112:7897`。
- **带用户名/密码的代理凭据不要写进仓库**，只在本地 shell 环境里设置；公开仓库会泄露。
- 需要认证代理时，用人类在本地提供的环境变量（例如 `PVF_PROXY`），不要硬编码。
- 验证连通性：

```bash
curl -sSI --proxy "$HTTPS_PROXY" https://github.com | head -1
```

如果直连和代理都失败，报告“网络不可用”，不要反复重试卡住任务。
