## 验收项（关闭 D 类前必须逐条通过）

- #20：视频/音频源帧 = `sourceIn + (当前帧 - 实体 start)`；预览与导出一致。
- #22：子实体范围必须被所有祖先包含；裁剪父级级联裁剪/删除子级；父范围外不渲染/不发声。
- #27：`entity.update` 改 row 不改父级；`entity.reparent` 必须显式给 `preserveWorld` 或 `keepLocal`。
- #31：`entity.trim` 删越界关键帧、级联裁剪/删除子级；扩大不恢复。
- #32：音频用实体 start/end + sourceIn，不引入 trimStart/trimEnd。
- #33：所有帧号整数；关键帧相对实体 start；越界返回允许范围。
- #35：所有写路径复核 locked，包括拖动、裁剪、关键帧、属性、批量写入。
