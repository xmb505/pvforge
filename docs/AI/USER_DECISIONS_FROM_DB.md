### 1.2 如何识别 `question` 调用与结果

`question` 不是独立表，而是 assistant 消息 `session_message.data` 里 `content[]` 的一个元素：

```text
content[i].type = "tool"
content[i].name = "question"
content[i].state.input.questions[]      # 问题、header、options、multiple
content[i].state.metadata.answers[]     # 每题一个数组，元素是选中的 label 或自由输入
content[i].state.content[0].text        # "User has answered your questions: ..."
content[i].state.status                 # completed / error
content[i].state.error                  # dismissed / interrupted
```

判定规则：

1. `status = completed` 且 `metadata.answers` 存在、`content[0].text` 以 `User has answered your questions:` 开头 → 计入回答。
2. `status = error`（`aborted` / `Tool execution interrupted`）→ 不计入回答；只记录题目被 dismissed/中断。
3. 答案字符串与某个 `options[].label` 完全相等 → 视为用户点选该选项。
4. 答案字符串不在 label 里 → 视为用户自由输入；其中 `?`、`详细说说`、`batch是什么`、`细说视频代理`、`ergonmics是啥`、`woc我知道该怎么做了` 等是**澄清/追问，不是决定**。
5. 空数组 → 该题未答，不替用户补默认值。

### 6.1 产品 / 平台 / 技术

- 基于 Mine-imator 大改，做音乐二次元 PV 编辑器；去掉深度，但核心交互逻辑保持 3D 工作流，让 3D 人员直接出片。`[选#1]`
- Qt / 全平台通用，Linux 优先；UI 纯原生 Qt，保留 KDE 原生菜单/主题能力。`[选#1][选#2][原seq 43758]`
- 只要新格式，不兼容旧工程；旧 app 只作参考，最终删除并把新工程改名。`[选#1][原seq 46208]`
- 单用户产品；git 友好、AI 友好；数据拆小、命名稳定、可 diff/回滚。`[原seq 46208]`

### 6.2 工程 / 数据模型 / 实体

- 时间轴上的元素叫**实体**；素材挂在实体上，实体素材可换；实体名可重复，默认素材名；UUID 给 AI 用。`[原seq 46208]`
- 实体 `start`/`end` 是**绝对全局帧**，半开区间；关键帧表**相对实体 start**；拖实体时关键帧跟着实体走。`[选#31][原seq 46208]`
- 子实体 `transform` 是局部坐标、继承父变换；父移动/旋转/缩放时子实体渲染继承，不改子文件。`[选#31][选#34]`
- 子实例默认继承位置/旋转/缩放/透明度/可见性；可在 Inherit 面板改。`[选#21]`
- 任意实体可当父实体；文件夹也是实体，可开私有时间线；空实体 = 容器 + 素材插槽。`[选#23][选#30][选#31][选#32]`
- 没有场景对象/场景文件夹/场景写权限；用空实体替代。`[选#30]`（覆盖 `[选#18][选#19]`）
- 全局 markers 保留：不占行、不渲染、不影响时间轴长度；关键帧可加备注，AI 只读。`[选#14][选#36]`
- 工程目录式，一实体一文件；素材用 sha256，只有时间线实体要 UUID。`[选#30]`
- 工程格式 `formatVersion 2`，加载器兼容 v1/v2，单向兼容。`[选#15]`
- 删除父实体时**级联删除**子实体；删除视频时拆出的音频**完全不提示**。`[选#39][选#64]`（MCP 是否允许删除见 3.i）
- row 每个父级独立、持久化；row 0 在最底；时间线学 PR 从下往上。`[选#34][选#35]`
- 新实体默认 row = 整个范围最高行 + 1；MCP 新建默认叠最上面。`[选#36][选#34]`
- 图层顺序：上面的实体遮挡下面的；行是固定槽位，删第一行不能让第二行自动上移；第 3/4 行要能渲染；拖到深处不能自动回第一行。`[原seq 43779]`

### 6.3 时间轴 / 轨道 / clip

- 时间轴**无限长**；播放到内容末尾；刻度按项目帧率，24FPS 时 0–1s 有 24 格；刻度标注正对播放条中心。`[选#41][选#69][原seq 7705][原seq 45556]`
- 轨道：每个实体一行、行数无限；不分固定的 V/A/相机轨类型；同轨不重叠。`[选#24][选#25][选#21]`
- 播放指示条**永远待在可视时间轴内**；往左拖整个时间轴往左走，右边同理；倒三角指针要显示。`[原seq 41898][原seq 45319]`
- 帧/秒两种显示模式；帧模式可走到几千帧；左右键一次一帧，长按播放/倒退。`[原seq 7831][原seq 7268][原seq 8148]`
- Ctrl+滚轮缩放、Shift+滚轮左右、滚轮上下；横向滚动条不自动隐藏、留余量；要有竖向滚动条；可拖到天荒地老。`[原seq 2520][原seq 25803][原seq 39741][原seq 39825]`
- 点秒数栏跳转/拖 scrub；点关键帧只选中不跳转；空白拖动框选；点其他位置取消选中。`[原seq 3430][原seq 3699]`
- 私有时间线用**浮层弹窗**，不打开新子页面；长度跟随父 clip、不缩放；可嵌套；单面板 + 面包屑栈。`[选#65][选#23][选#22][选#21]`
- 私有时间线只保留轨道，不塞素材盒；素材盒在主时间轴旁。`[原seq 39017][原seq 41298]`
- `+` 按钮放在 clip 上（用户后来要求放右边、居中）；点击出悬浮时间线；end 不在窗口内时渲染在 clip 最靠近窗口边缘处。`[选#67][原seq 39300][原seq 41818]`
- 实体改名只在属性栏；双击实体条=打关键帧；`+` 打开子时间线。`[选#67]`
- 私有时间线相对/绝对两种模式；播放轴不在父时间轴范围内不渲染。`[原seq 39150][原seq 42376]`
- 父 clip 移动时子实体跟着走；父 end 拉过来视觉裁剪子实体，松手才提交；父 end 越过子 start 就删。`[选#26][选#22][选#23]`
- 裁剪不移动内容、删越界关键帧；end 从 5s 拉到 3s 再拉回 5s，4s 的 key 应删除，不能复活。`[选#31][原seq 39568]`
- clip 可上下移动；第 7/8 行等深处要能拖到；空子时间轴只占一行，有一个 clip 就两行。`[原seq 39520][原seq 39978][原seq 45264]`
- clip 可被拦腰斩断成两个；clip 学 PR 做收尾吸附；切分带子实体的父实体要递归切分/复制。`[原seq 45665][选#64]`
- 歌词/字幕用**文字层 + 关键帧**，不单独做字幕/歌词轨。`[选#20]`
- 所有实体（文字/矢量/文件夹/音频/相机）都有 start/end clip，默认 **1s**；裁剪规则对全部适用。`[选#26]`
- 从工作台创建元素，start 落在当前播放条；视频实体默认长度=视频长度；导出的视频长度跟摄像机存活时间走。`[原seq 45594][原seq 45417][原seq 45528]`
- 新实体 start：AI/MCP 创建必须给 `startTime`；人类点按钮对齐播放轴；素材箱拖入对齐鼠标。`[选#43]`
- 视频导入自动拆成视频 + 音频两个素材；拆出后**完全独立**，删除视频时不提示音频。`[选#32][选#33][选#64]`

### 6.4 关键帧 / 曲线 / 求解 / 物理

- 关键帧分普通关键帧（知道起点终点）与求解关键帧（知道起点求终点）；求解结果运行时实时算。`[选#49][原seq 46632]`
- 求解数据 = 求解开始帧 + 求解结束帧；没有结束帧只能到 clip 最后一帧；结束帧后才能继续普通关键帧；开始帧带值，结束帧只是标记。`[选#49][选#59]`
- 求解开始必须先有普通关键帧，再由人类转成求解开始帧。`[选#65]`
- 求解段一个段一个效果，不能重叠；驱动属性由效果决定；结束帧后停在结束帧。`[选#55]`
- 物理效果第一版：重力 / 公转 / 自转 / 黑洞；重力方向由实体决定（长方形可做地面）；公转对象用实体 UUID，椭圆经过求解开始点，速度用周期（帧/圈）；公转参数含左右方向、椭圆角度。`[选#50][选#54][选#51][选#52][选#53]`
- 碰撞：运动物体按实际矢量形状；非矢量用包围盒；物理干涉开关可关键帧；撞所有开了开关的实体；重力撞地面反弹，参数弹性+摩擦+停止阈值。`[选#56][选#57][选#58]`
- 黑洞：参数含黑洞实体/模拟速度/质量/角动量/初始向量（预览手柄可拖，可逃离）；进入视界后继续飞；旋涡只改坐标。`[选#54][选#59][选#58]`
- 曲线/缓动：先给函数模板（二次/三次等），用户在右侧属性里选预设或自定义；不单开 tab、不右键选缓动、不做图表/波形 tab；第一帧没有进入曲线，曲线属于到达的关键帧。`[选#66][原seq 11221][原seq 12351]`
- 选中关键帧后属性面板显示该关键帧信息，不是播放条位置信息。`[原seq 28993]`
- 关键帧可拖动/删除/Ctrl+Z 恢复；点选变色；双击 clip 内部快速创建；合并菱形拖动=整帧所有 key 一起动；复制只同实体同轨道。`[原seq 42447][原seq 42511][选#66][选#67][选#68]`
- Auto-key 默认开；关键帧属性按钮 + auto-key + clip 双击三种打 key 方式。`[选#67][选#66]`
- `rotPointX/Y` 必须按真轴心语义实现，或重命名并在 MCP 文档写清，不能继续用“轴心”误导；vector 建议加 width 轨道。`[原seq 45870]`
- 关键帧位置校验：不能出现文件夹只有 30 帧、却在 90 帧藏 key、表面还显示 30 帧。`[原seq 45803][原seq 45840]`

### 6.5 素材 / 媒体

- 素材类型：图片/视频/文字/矢量/HTML/音频/摄像机；图片和视频统一成实体。`[原seq 5775][原seq 666]`
- 素材用内容哈希（sha256）标识/入库；同名不同文件不冲突；同 hash 去重保留首名；素材不需要 UUID。`[选#30][选#42]`
- 右侧素材库与 Mine-imator 一样；素材管理借鉴 Blender；矢量库要有矩形/三角形/圆形/心形/星形/箭头等大量图标。`[原seq 5775][原seq 3962][原seq 5832]`
- 素材箱做成文件夹样式、可列表/图标、平铺+搜索+标签；悬停出小浮窗预览；不要把“创建实体/删除”按钮放素材库；删除用 Del 或右键 clip。`[选#86][原seq 41898][原seq 42788]`
- 素材库 `+` 可选择所有文件丢进来，由软件识别能否入库；导入慢要有等待条，或异步 + 底部提示栏。`[原seq 5202][原seq 6042][原seq 6057]`
- “素材 > 全部打包到项目”默认关闭，用户手动开启；开启后自动复制进工程文件夹。`[原seq 3962][原seq 3977]`
- 工作台只显示缩略图，实际渲染/导出才上高清原图；视频拖动卡要有后台预览压缩或硬解。`[原seq 4700][原seq 17945]`
- 实体可更换素材，从素材库选并显示预览；换素材时实体时长自动裁到新素材时长；按兼容组互换（视觉/生成内容/音频/摄像机）。`[原seq 27192][原seq 28394][选#38][选#35]`
- 混合模式：标准混合 + MI 颜色混合（Blend color / Mix color / Mix percent 等）。`[选#21][选#24]`
