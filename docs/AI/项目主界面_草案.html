舞台 STAGE · 术语对齐

舞台 Stage = 整个合成窗口（本页） ├─ 视口 / 画布 看画面的视图，不是舞台本身 ├─ 工作台 创建 / 导入 / 配置实体的面板 ├─ 属性 当前选中实体的参数 ├─ 素材库 图片 / 视频 / 音频 / SVG ├─ 时间轴 轨道（图层）+ 片段（实体） │ ├─ 轨道 只是行号/图层，不绑实体 │ ├─ 片段 实体自己注册，占一行 │ └─ 私有时间线 ± 轨道围绕父实体，可无限展开 └─ 监视器 摄像机输出预览
工作台浮出 / 停靠 = 舞台内面板行为，不是“打开另一个舞台”。
本页是施工图草案，人类确认后才进入 docs/AI-HUMAN。
