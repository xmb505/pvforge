1. 工程目录拓扑（按实体 UUID 扁平拆文件）

PROJECT_DIR/ （Git 友好 · AI 友好）
my_pv/
├── project.json          # 帧率/画布/播放条位置/全局设置
├── assets.json           # 素材索引（哈希 -> 路径/元信息）
├── assets/               # 按需打包（默认关，开启时存哈希文件）
├── entities/             # 扁平化：每个实体/片段一个文件
│   ├── <uuid-A>.json
│   ├── <uuid-B>.json     # parentUuid 指向 A，不嵌套目录
│   └── <uuid-C>.json
└── .git/                 # 可选（开启后解锁 MCP 与跨会话落盘）
entities/<uuid>.json 核心字段
{
  "uuid": "e1b2...",
  "name": "字幕1",        // 可重复
  "type": "text",
  "parentUuid": "root",   // root=舞台，或父实体 UUID
  "track": 2,             // 所属轨道行号（私有时间线可正负）
  "start": 10, "end": 90, // 必须为父区间的子集
  "followParentRange": false,
  "inherit": { "pos": true, "rot": true, "scale": true, "opacity": true },
  "tracks": { ... },      // 相对关键帧（无独立属性则跟父）
  "ext": { ... }          // 拓展参数
}
