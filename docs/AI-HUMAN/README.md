# AI-HUMAN

**AI 起草、人类逐条确认**的文档。这里是施工图的唯一合法位置。

和另外两个目录的区别：

| 目录 | 作者 | 可信度 | 用途 |
|---|---|---|---|
| `docs/AI/` | AI | 低 | 草案、审计、分析、交接；不能当需求 |
| `docs/human/` | 人类 | 最高 | 人类原话、规则、伪代码；AI 不得代写 |
| `docs/AI-HUMAN/` | AI 起草 + 人类确认 | 已确认 | 施工图；实现和验收依据 |

## 施工图规则

- 施工图**必须是 HTML**，不是 Markdown。
- 每份 HTML 顶部写：状态（已确认）、确认日期、适用模块、确认人、关联 issue。
- 未确认的 HTML 草案放 `docs/AI/`；人类确认后才移到本目录。
- 与代码冲突时，施工图是目标，代码是现状；先记录漂移，再修代码。
- 修改已确认施工图，必须在 HTML 末尾写变更记录。
